For now, new subscriptions are paused and renewals are stopped; existing access runs until the current period ends. Manage your account.

It stays a browser extension, not a standalone app.

That was the whole point from the very beginning. There are already hundreds of standalone downloader apps, so there is no reason to reinvent the wheel. Comics Downloader stays lightweight, accessible and built right into your browser.

Release

Out on 22 November.

Sunday 22 November, 12:00 UTC

Chrome and Firefox first. Edge and Opera follow once their stores have reviewed it. If you already have Comix Downloader, it updates itself.

What stays open source

The rewrite's codebase will remain private. The extension that is already released stays open source on the v4 branch on GitHub.

A new name

Comix Downloader becomes Comics Downloader with this release.

Missing a site?

Suggest it on the announcement thread. New requests go on the to-be-implemented list.

In the meantime

The current Comix Downloader is on the Chrome and Firefox stores. Keep it installed: it updates to 5.0 on its own.
